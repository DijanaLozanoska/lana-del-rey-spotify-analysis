# 🎧 Lana Del Rey Spotify Listening Analytics

• End-to-End Data Analytics Project • Oracle SQL • Star Schema Modeling • ETL • Power BI • 

---
## 📌 1. Project overview

This project presents an end-to-end analysis of Lana Del Rey listening activity using my own personal Spotify Extended Streaming History data.

The project demonstrates how raw semi-structured JSON data can be transformed into a relational dimensional data warehouse in Oracle SQL and subsequently analyzed through an interactive Power BI semantic model and dashboard.
