# 🎧 Lana Del Rey Spotify Listening Analytics

• End-to-End Data Analytics Project • Oracle SQL • Star Schema Modeling • ETL • Power BI • 

---
## 📌 1. Project overview

This project presents an end-to-end analysis of Lana Del Rey listening activity using personal Spotify Extended Streaming History data, transforming raw JSON data into a dimensional data warehouse in Oracle SQL and an interactive Power BI dashboard.

---

## 📂 Dataset

Main objective is to keep only artist Lana Del Rey records in the JSON file and remove private metadata.
