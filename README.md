# 🎧 Lana Del Rey Spotify Listening Analytics

• End-to-End Data Analytics Project • Oracle SQL • Star Schema Modeling • ETL • Power BI • 
---

## 📌 1. Project overview

This project analyzes Lana Del Rey listening behavior using Spotify my own streaming-history data. End-to-End Data Analytics Project utilizing an enterprise stack: The raw JSON data is cleaned with Python to remove unnecessary and potentially identifying metadata, exclude non-music records, and filter listening events to Lana Del Rey Oracle SQL for database warehousing, Star Schema Modeling for optimization, ETL/ELT via the Medallion Architecture, and Power BI for executive dashboards.

---

## 📂 Dataset

Main objective is to keep only artist Lana Del Rey records in the JSON file and remove all other private metadata such as IP address
